## AI Process Assurance

> If an auditor asks in three years why an AI-assisted decision was made, what will you show them?

Our answer is to compare the path a workflow was *supposed* to follow with the path it *actually* followed.

| | |
| --- | --- |
| **Workflow Charter** — the expected path | Required stages, evidence, authority limits and approval gates. Persistent memory that keeps an assistant on the designated path across sessions. |
| **Semantic Audit** — the actual path | Steps taken, evidence used, decisions made and approvals given, captured as the assistant works, in business-readable form. |
| **AI Workpaper** — the artifact | A retained evidence record: context, timeline, actions, evidence sources, decisions, approvals, exceptions and outcome. |

Semantic Audit stands alone for retrospective evidence. Workflow Charter stands alone for process memory and guidance. Together they give you exception detection and operational control.
